# DI × BCG Circelligence + SAP: competitive analysis for Hilti AMS

A single-page static site. No build step, no dependencies, no external requests.

## Publish on GitHub Pages

1. Create a repository and add `index.html` and `.nojekyll` to the root.
2. In the repository, open Settings, then Pages.
3. Under Build and deployment, choose "Deploy from a branch", select `main` and `/ (root)`, and save.
4. The site appears at `https://<user>.github.io/<repository>/` after a minute or two.

## Notes

- `index.html` contains `<meta name="robots" content="noindex">` so search engines do not list it. Delete that line if you want it indexed.
- A public repository makes the page public. Use a private repository with GitHub Pages access control if the content should stay internal.
- Research cut-off is 5 November 2026. DI is a proposed product; no deployment or measured result is claimed.
